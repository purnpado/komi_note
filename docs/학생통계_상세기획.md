# 학생 통계 상세 기획

> 상태: 기본 현황은 구현됨. 제출 서류와 설문은 각각 현재 UI를 유지하며, 설문 작성 화면의 블록 폼 빌더 전환은 다음 작업 후보다.

> 구현 원칙(2026-10-09): 학생 참여형 기능은 Wails v2 데스크톱 앱을 교사용 관리·로컬 서버로 사용하고, 학생·전자칠판은 교실 Wi-Fi 안에서 브라우저로 접속한다. 외부 공개 서버나 학생 앱 설치는 요구하지 않는다.

## 목적

학생 기본 현황, 제출 서류, 학급 설문과 학년·학교급 취합을 암호화 보관함 안에서 관리한다. 통계 메뉴의 기본 탭은 기존 학생 기본 통계 화면으로 유지한다.

## 탭 구성

```text
기본 현황 | 제출 서류 | 설문 통계 | 통계 취합
```

### 기본 현황

- 재학생 수, 남·여 인원, 기준일 기준 만 나이별 인원·명단
- 생년월일·주소·학생 연락처·보호자 연락처 보완 필요 현황
- 전입생 현황과 학적변동 학생 현황 분리 표시
- 전체·성별·정보 보완 필요 필터와 학생 검색
- 학생 이름을 누르면 학생 상세정보로 이동

### 제출 서류

- 교사가 서류 항목의 제목, 분류, 마감일, 안내 메모를 직접 만든다.
- 예: 학생기초조사서, 개인정보 활용 동의서, 건강조사서, 가정통신문 회신서
- 기본 제출 상태는 `미제출`, `제출`, `확인 필요`, `면제`로 제공한다.
- 학교 업무에 맞는 추가 상태는 사용자가 직접 만들고 이름·색상·표시 순서를 수정·삭제할 수 있다.
- 학생별 상태, 제출일, 교사 메모를 기록한다.
- 서류별 카드 보기와 학생별 목록 보기를 제공한다.
- 마감일이 지난 미제출 상태를 강조하고 필터링한다.
- 학생 상세정보에는 미제출 서류 개수만 요약한다.
- 첫 구현에서는 서류 원본 파일을 보관하지 않고 제출 여부 관리에 집중한다.

### 설문 통계

- 교사는 문항 번호와 질문을 빠르게 입력한다.
  - 예: `1-1. 학교생활에 만족한다.`
- 문항 유형: 5점 척도, 예·아니오, 하나 선택, 여러 개 선택, 숫자, 짧은 서술형
- 자주 쓰는 선택지는 공통 척도로 저장해 재사용한다.
- 설문별 설정: 제목, 안내문, 응답 마감, 응답 수정 허용, 학급 내부용·학년 취합용, 익명·실명 응답
- 설문 상태: `작성 중 / 진행 중 / 마감 / 결과 확정`
- 문항을 수정하면 기존 응답과 섞이지 않도록 설문 버전을 새로 만든다.

#### 교직원용 설문

- 교직원용 설문은 향후 `업무용 > 설문 통계` 메뉴로 분리한다. 현재 설문 작성 화면에서도 대상만 `교직원`으로 지정해 사용할 수 있다.
- `익명`: 학교 메신저로 교내망 주소를 전달하면 이름 입력 없이 바로 참여한다. 교사는 응답자 수와 답변만 본다.
- `이름 입력`: 응답 시작 전에 이름을 한 번 입력한다. 그 이름과 답변은 암호화 보관함의 교사 화면에서만 연결해 확인한다.
- 이름 입력은 간편한 확인 방식이며, 타인 이름 입력을 완전히 막는 본인 인증은 아니다. 엄격한 신원 확인이 필요한 설문은 추후 개별 초대 코드 방식으로 확장한다.
- 교내 Wi-Fi·유선망의 로컬 주소만 제공하며, 외부 인터넷 공개 서버는 사용하지 않는다.

#### 전자칠판·학생 화면과 교사 화면의 분리

- 교사 컴퓨터는 전자칠판에 연결해 QR 코드, 참여 안내, 익명 집계 현황을 송출한다.
- 학생이 보는 화면과 전자칠판 화면에는 학생 이름·개별 응답을 표시하지 않는다.
- 학생 설문은 전자칠판·학생 화면에만 익명으로 표시하며, 교사 화면에서는 설문 설정과 무관하게 다음 정보를 확인할 수 있다.
  - 학생별 응답 여부와 미응답자
  - 학생별 선택·서술 응답
  - 응답 시각
- 교직원 설문의 `익명` 방식은 이름 자체를 받지 않으므로 교사도 이름과 응답을 연결해 볼 수 없고, 인원·비율만 확인한다.
- 진행 중 결과 공개 여부는 교사가 선택하며, 기본값은 교사만 확인이다.

### 통계 취합

- 반별 집계 파일에는 학년도, 학년, 반, 설문 식별값, 문항 번호, 응답 항목, 응답자 수만 담는다.
- 학생 이름·생년월일·개별 응답 원문은 취합 파일에 포함하지 않는다.
- 학년부장·담당자는 여러 반의 집계 파일을 불러와 문항별·응답별 합계와 비율을 확인한다.
- 서술형은 반 안에서만 확인하고, 필요한 경우 교사가 익명화·선별한 의견만 별도로 내보낸다.

### 교실 참여 기반

- 교사 PC가 교내 Wi-Fi 안에서만 임시 참여 서버를 시작한다.
- 프로그램이 QR 코드와 교내 주소를 직접 생성한다.
- 학생은 이름, 생년월일, 전자칠판에 표시한 공통 참여 코드로 확인한다.
- 설문·활동별 학생 1회 참여를 제한하고, 교사가 종료하면 주소·QR·참여 세션을 즉시 무효화한다.
- 접속 IP·기기 정보는 기본 저장하지 않는다.
- 자리배치, 청소구역, 모둠편성은 이 참여 기반만 재사용하며 세부 규칙은 각각 구현 시 별도 설계한다.

## 구현 상태와 이후 순서

1. 기본 현황: 구현됨.
2. 제출 서류: 현재 담임용 메뉴에서 관리 화면을 제공하며, 상세 상태·마감일 확장은 별도 승인 범위다.
3. 설문: QR 참여·기본 결과 기능은 유지하고, 다음 구현에서 카드형 블록 폼 빌더로 작성 화면을 전환한다.
4. QR 참여 서버와 전자칠판: 자리배정·설문에서 교실 내부 주소 방식으로 사용 중이다.
5. 개인정보 없는 반별 집계 파일 내보내기와 학년·학교급 취합: 미구현이다.

## 개인정보 원칙

- 모든 원본 응답과 제출 상태는 로컬 암호화 보관함에 저장한다.
- 외부 취합 파일에는 개인정보와 개별 응답 원문을 넣지 않는다.
- 참여 서버는 교사가 명시적으로 시작했을 때만 작동한다.
