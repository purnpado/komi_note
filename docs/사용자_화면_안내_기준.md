# 사용자 화면 안내 기준

마지막 갱신: 2026-10-21

## 목적

꼬미노트를 처음 사용하는 교사가 별도 매뉴얼을 찾지 않고도 화면 안에서 업무를 시작할 수 있게 한다.

## 모든 기능의 기본 구성

1. 화면 상단에 접을 수 있는 `처음 사용 안내` 카드를 둔다.
2. 안내 카드에는 실제 사용 순서를 번호로 보여준다.
3. 파일 업로드·삭제·출력·외부 연동처럼 실수 위험이 있는 조작에는 준비물과 결과를 명시한다.
4. 버튼과 입력값 중 오해하기 쉬운 곳에는 키보드 포커스를 지원하는 `?` 툴팁을 둔다.
5. 개인정보 화면에는 암호화 보관·외부 전송 여부를 짧게 설명한다.

## 현재 안내 적용 화면

| 화면 | 안내 내용 |
| --- | --- |
| 환경 설정 | 학급 기본정보, 자동 잠금, 테마, 교외체험학습 기준 |
| 학생 명렬 | 나이스 명렬표 출력·열 선택·엑셀 내려받기·가져오기 확인 |
| 학생 상세정보 | 사진, 기본정보·연락처 보완, 복사, 상담·출결 확인 |
| 학생 통계 | 기준일 선택과 만 나이·성별 통계 확인 |
| 출결 관리 | 출결 입력, 학교 서식 등록·좌표 지정, 출결 서류 출력 |
| 출결 서식 도움말 | HWPX 복사본에 치환자 넣기, 보호자 성명 규칙, 원본·개인정보 보호 |
| 청소구역 배정 | 기간·구역 설정, 교사 직접 편성, 경고·이력·인쇄 |
| 자리배정 | 배치도 설정, 고정 학생, QR 회차와 게임 진행, 최종 실명 자리 확인 |
| 상담 기록 | 학생 선택, Radix 대화상자에서 기록·조회·후속 기록·삭제 확인 |

## 나이스 명렬표 안내 문구

명렬표 가져오기 화면에서는 다음 순서로 안내한다.

1. 나이스의 `명렬표 출력`에서 `명렬표 내용 선택`을 연다.
2. `성별`, `생년월일`, `주소`를 선택하고 `추가` 후 `선택 자료 추가`를 누른다.
3. 내려받은 엑셀 파일을 꼬미노트에 업로드한다.

학년·반은 나이스 명렬표에 기본으로 표시되는 항목이므로 교사에게 별도로 선택하라고 안내하지 않는다.

## 작성 원칙

- 전문 용어보다 교사가 나이스와 학교 업무에서 실제로 쓰는 말을 우선한다.
- 안내는 짧게 쓰되, 순서와 필요한 파일 형식은 생략하지 않는다.
- 기능이 바뀌면 같은 커밋에서 안내 문구도 함께 갱신한다.
- 설문은 블록 폼 빌더 리팩터링 전까지 기존 안내를 유지하고, 리팩터링 완료 커밋에서 새 작성·미리보기·참여·결과 흐름으로 갱신한다.
