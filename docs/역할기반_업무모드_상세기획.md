# 역할 기반 업무 모드 상세기획

> 상태: **1차 구현 완료 · 담임/비담임 역할 선택과 메뉴 분리는 적용됨. 수업 명렬·시간표·수행평가·모둠 편성 등 수업용 실제 입력 기능은 미구현.**

## 목적

꼬미노트를 담임뿐 아니라 비담임 교과 교사도 사용할 수 있게 한다. 역할과 무관한 학생 개인정보 메뉴를 처음부터 숨기고, 교사의 실제 업무 흐름에 맞게 `담임용 · 수업용 · 업무용`으로 화면을 나눈다.

## 최초 환경 설정

첫 단계에서 이용자 역할을 선택한다.

| 역할 | 필수 입력 | 열리는 메뉴 |
| --- | --- | --- |
| 담임 교사 | 학교명, 학년도, 교사 표기, 담임 학년·반, 담당 교과, 수업 학년·반, 보안 설정 | 담임용, 수업용, 업무용 전체 |
| 비담임 교과 교사 | 학교명, 학년도, 교사 표기, 담당 교과, 수업 학년·반, 보안 설정 | 수업용, 업무용 |

- 담임·비담임 모두 담당 교과와 수업 학년·반을 여러 개 추가·수정할 수 있다.
- 최초 설정에서는 역할을 동시에 선택할 수 없는 선택 버튼으로 제공한다. 비담임을 고르면 담임 학년·반 입력 영역만 비활성화한다.
- 기존 사용자는 업데이트 뒤 기본값을 `담임 교사`로 유지한다.
- 환경 설정에서 역할을 바꿔도 기존 학생·상담·출결 데이터는 삭제하지 않고, 역할에 맞지 않는 화면만 숨긴다.

## 왼쪽 메뉴 구조

```text
오늘
  대시보드

담임용              ← 담임 교사에게만 표시
  학생 명렬
  학생 통계 · 제출 서류
  상담 기록
  출결 관리
  학급 운영

수업용
  수업 명렬
  반 시간표 · 교사 시간표
  수행평가
  학교생활기록부
  수업 설문
  모둠 편성

업무용
  교직원 설문
  메모 · 할 일
  일정 · 구글 캘린더
  예산 관리
  환경 설정
```

### 현재 기능 재분류

| 현재 기능 | 새 위치 | 비담임 사용 |
| --- | --- | --- |
| 학생 명렬, 기본 현황, 제출 서류, 상담, 출결, 학급 운영 | 담임용 | 불가 |
| 학생 통계의 만 나이·개인정보 현황 | 담임용 | 불가 |
| 학생 대상 QR 참여 설문·전자칠판 공개 화면 | 수업용 > 수업 설문 | 가능 |
| 교직원 설문 | 업무용 > 교직원 설문 | 가능 |
| 수업 명렬, 수행평가, 교과세특, 창체, 행동특성, 자유학기제, 시간표, 모둠 편성 | 수업용 | 가능 |
| 예산, 메모·할 일, 일정, 환경 설정 | 업무용 | 가능 |

## 대시보드

- 담임: 오늘 출결, 상담 후속 조치, 학급 일정, 제출 서류 미제출, 학급·교사 시간표
- 비담임: 오늘 수업, 평가 입력 진행률, 수업 설문 진행 현황, 개인 일정·할 일, 교사 시간표

## 용어 원칙

- 공통 기능에서는 `담임` 대신 `교사`, `수업`, `학급`, `업무`를 쓴다.
- 결석 신고서처럼 학교 공식 양식에 적힌 `담임교사`는 임의로 바꾸지 않는다.
- 현재 브랜드 설명인 `나의 학급 업무공간`은 역할에 따라 `나의 학교 업무공간`으로 바꾼다.

## 수업 명렬·수행평가 연결

- 수업 명렬은 나이스 엑셀 또는 수기 입력으로 관리하며, `학년·반·번호(또는 나이스 학번)·성명·재학 상태`만 저장한다.
- 주소·연락처·보호자·사진·상담·출결은 수업용 명렬에 저장하거나 표시하지 않는다.
- 전입은 수기 추가 또는 명렬 재가져오기로 반영하고, 전출·유예·자퇴·면제·정원외·조기졸업은 활성 수업 대상에서 제외한다. 기존 수행평가·교과 기록은 최종 정리 전까지 보관 상태로 유지한다.
- 나이스 수행평가 일괄등록 파일의 `과목·반·번호·성명`과 평가 항목·만점을 읽어 수업 명렬과 수행평가 항목을 미리 채운다. 교과별 평가 항목 수·배점은 제한하지 않는다.
- 교과 담당 교사는 항목별 세부 채점 기준·배점·학생별 채점 근거·감점 사유·피드백을 직접 입력한다. 총점 직접 입력과 기준별 점수 합산을 함께 지원한다.
- 학생 개인 점수 확인은 외부 학생 접속이 아닌 교사 노트북에서 반번호 또는 성명으로 학생 한 명만 선택해 표시한다.

## 설문 기능 연결

- 학생 대상 설문은 수업용 > 수업 설문에 둔다. 담임은 담임 학급 수업, 비담임은 담당 수업 설문으로 이용한다.
- 교직원 대상 설문은 업무용 > 교직원 설문에 둔다. 익명은 이름 없이, 이름 입력 방식은 교사 화면에서 이름과 응답을 함께 확인한다.
- 비담임 설문은 담당 교과·수업 학년반을 선택해 분류한다.
- 기존 설문 데이터는 유지하며, 역할 기반 메뉴 구현 시 생성 교사 역할·수업 대상만 선택 항목으로 추가한다.

## 학년도 전환과 비식별 재사용 자료

- 교사가 환경 설정에서 `새 학년도 시작`을 직접 선택하면 기존 학년도는 암호화 보관·읽기 전용으로 전환한다.
- 새 학년도에는 역할을 다시 선택하고, 학교명·교사 표기·보안 설정·담당 수업은 복사 후 수정할 수 있다. 학생 명렬·연락처·사진·상담·출결·점수는 복사하지 않는다.
- 업무용 템플릿·수행평가 기준과 학교생활기록부 특기사항의 본문만 선택적으로 재사용 자료함에 복사한다.
- 교과세특·창체·행동특성·자유학기제는 학생 번호·성명·학년·반을 제외한 특기사항 본문과 승인된 태그만 추출한다. 다음 학년도에는 `이전 특기사항 참조`에서 검색·복사한 뒤 현재 학생 내용으로 수정해 저장한다.

## 추가 권장 사항

- 점수가 입력된 수행평가의 기준·배점을 바꿀 때는 기존 항목을 새 버전으로 복제하고, 변경 전 점수를 조용히 바꾸지 않는다.
- 점수·채점 근거·피드백의 수정 이력은 암호화 보관함에 남긴다.
- 특기사항 추출 전 본문에 이름·구체적 사건·연락처 등 식별 가능 내용이 있는지 경고하고 교사가 제외·수정하게 한다.
- 수업 명렬 재가져오기 때 동일 학생은 신규 생성 대신 갱신·무시·검토 중 선택하게 한다.
- 수행평가 점수는 나이스 업로드 형식 엑셀로 내보내고, 채점 근거·피드백은 교사용 보관으로 분리한다.
- 교직원 설문에서 강한 본인 확인이 필요할 경우 개별 초대 코드 방식을 후속 확장한다.

## 제외 범위

- 교사 여러 명이 한 암호화 보관함을 공유하는 기능
- 나이스·학교 서버에서 담당 교과나 수업 반을 자동으로 수집하는 기능
- 역할 변경 시 기존 데이터를 자동 삭제하거나 외부로 전송하는 기능

## 1차 구현 결과 (2026-10-10)

- 최초 설정과 환경 설정에 `담임 교사`·`비담임 교과 교사` 선택을 추가했다.
- 비담임을 선택하면 학년·반 입력 칸을 비활성화하고, 담임용 메뉴를 화면에서 숨긴다.
- 담임과 비담임 모두 교사 표기·담당 교과·수업 학년·반을 저장할 수 있다.
- 좌측 메뉴를 `오늘 / 담임용 / 수업용 / 업무용`으로 재분류했고, 학생 설문은 수업용, 교직원 설문은 업무용으로 분리했다.
- 아직 입력 기능이 없는 수업 명렬·시간표·모둠 편성은 역할별 메뉴 자리와 안내 화면만 먼저 제공한다.

## 완료 기준

- 최초 설정과 환경 설정에서 역할을 선택·변경할 수 있다.
- 비담임 모드에 담임용 메뉴와 학생 개인정보 중심 화면이 표시되지 않는다.
- 담임 모드의 기존 기능과 데이터는 그대로 유지된다.
- 역할별 대시보드·첫 사용 안내·메뉴 문구가 실제 업무 범위에 맞게 보인다.
